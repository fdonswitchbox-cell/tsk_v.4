# Улитка v.3 / tsk_v.4 — движок принятия решений из заметок

Дизайн-бэклог и архитектура проекта «Улитка»: система, которая из обычных заметок пользователя строит карту проблем, целей и действий, рассчитывает приоритеты через граф знаний и выдаёт рекомендации.

## Назначение

- Извлекать из заметок структурированные сущности: проблемы, цели, действия, наблюдения, привычки, инсайты.
- Строить граф связей (co-occurrence, причинно-следственные цепочки).
- Автоматически приоритизировать действия (importance × связи × срочность × частота).
- Давать аналитику: тренды, корреляции, корневые причины, повторяющиеся проблемы.
- Отвечать на вопросы через LLM с опорой на инсайты и топ-действия.

## Стек (проектируемый)

- **Backend:** Python, FastAPI, PostgreSQL (15 таблиц), SQLite (MVP)
- **AI:** LLM через Ollama (qwen2.5:1.5b), эмбеддинги bge-m3
- **Граф:** собственный co-occurrence граф (NetworkX-style, в памяти / таблицы entity_links)
- **Оркестрация:** n8n (workflow v3-full-stack.json)
- **Развёртывание:** Docker Compose (v3-api, LightRAG, PostgreSQL)

## Модули (по стэку v.4)

1. `chunker.py` — разбивка заметки на наблюдения
2. `extractor.py` — LLM-извлечение сущностей (entities, problems, actions, observations)
3. `db.py` — запись в PostgreSQL
4. `graph_builder.py` — построение графа co-occurrence + генерация действий
5. `priority.py` — скоринг действий через граф
6. `insight_engine.py` — 4 анализатора (тренды, корреляции, root-cause, рекуррентность)
7. `insight_ranker.py` — топ-N по confidence
8. `answer_engine.py` — POST /v3/ask

## Запуск (ориентировочно)

```bash
docker compose up -d
docker compose run v3-api python3 /app/app/test_runner.py
```
