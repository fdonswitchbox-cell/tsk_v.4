    │
    ▼
1. chunker.py        → разбивка на наблюдения (observations)
2. extractor.py      → LLM (qwen2.5:1.5b) → entities, problems, actions, observations
    │
    ▼
3. db.py             → запись в свои таблицы:
    ├─ entities       — извлечённые сущности
    ├─ problems       — выявленные проблемы
    ├─ extractions    — сырой JSON от LLM (аудит)
    └─ entity_stats   — агрегированные метрики
    │
    ▼
4. graph_builder.py  → свой граф co-occurrence:
    ├─ entity_links   — entity1 ↔ entity2 (сила = кол-во совместных заметок)
    └─ генерация действий (actions)
    │
    ▼
5. priority.py       → скоринг действий через граф:
    ├─ взвешивание (importance × out-degree × in-degree × recency)
    └─ top_actions — реальные проблемы пользователя
    │
    ▼
6. insight_engine.py → 4 анализатора:
    ├─ trend_rising/falling    — растущие/падающие проблемы
    ├─ correlation             — связанные пары сущностей
    ├─ root_cause              — корневые причины (out-degree)
    └─ recurrence              — повторяющиеся проблемы
    │
    ▼
7. insight_ranker.py → топ-N по confidence, без дублей
    │
    ▼
8. answer_engine.py  → POST /v3/ask:
    ├─ intent classifier (LLM)
    ├─ evidence builder (insights + top_actions)
    └─ ответ генератор (LLM)
